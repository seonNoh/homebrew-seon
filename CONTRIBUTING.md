# Contributing to homebrew-seon

Thank you for improving the Seon Homebrew tap. Keep every change focused and preserve the generated release metadata.

## Generated Cask policy

`Casks/seon.rb` is generated by the Seon CLI release pipeline through GoReleaser. Do not edit its version, URLs, or checksums manually. When a generated Cask is incorrect, fix the release pipeline and publish a corrected generated file.

## Local validation

Run all repository checks before opening a pull request:

```bash
python3 verify.py
python3 -m unittest tests/test_verify.py -v
ruby -c Casks/seon.rb
```

When Homebrew developer tooling is available, also run:

```bash
brew audit --cask seonNoh/seon/seon
```

## Pull requests

- Explain why the change is needed and how it was verified.
- Keep the English, Korean, and Japanese README files structurally aligned.
- Update all affected language-specific diagrams together.
- Do not add secrets, credentials, generated caches, or editor state.
- Use an English Conventional Commit title and describe the reason and impact in Korean in the commit body.
